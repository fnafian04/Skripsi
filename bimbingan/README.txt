FILE NAFINDER

1. hasil_scraping_ulasan_wfc.xlsx
   Spreadsheet hasil scraping dalam format Excel.
   - Sheet "Ringkasan": ukuran file, jumlah baris, jumlah kafe, validitas,
     distribusi rating, dan daftar kolom.
   - Sheet "Data Scraping": seluruh 109.778 baris data scraping.
   - Header sudah dibuat sebagai tabel Excel, filter aktif, dan baris pertama
     dibekukan agar mudah dibaca.

2. gambaran_ui.html
   Gambaran ringkas UI aplikasi.
   Buka di browser, lalu gunakan Ctrl+P jika ingin mencetak atau menyimpan
   sebagai PDF.
   Halaman yang ditampilkan:
   - Dashboard
   - Kelola Dataset
   - Rekomendasi Kafe
   - Hasil Klasifikasi

- Spreadsheet berasal dari uploads_tmp/ulasan_wfc_final.csv dan tidak mengubah
  dataset asli.
- Angka model pada halaman UI merupakan contoh tampilan berdasarkan hasil
  eksperimen.
