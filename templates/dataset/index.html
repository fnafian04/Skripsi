Transparansi Metode Penelitian

Struktur & Tahapan Komputasi Teks

Pelajari alur algoritma from-scratch yang diterapkan pada ulasan kafe

1 Cleaning

1. Text Cleaning

Membersihkan tautan web (http/www), mention (@user), tagar (#viral), emoji unicode, angka, serta seluruh simbol tanda baca non-alfabet

Contoh: "kopinya enak bgt! @cafe ☕" → "kopinya enak bgt cafe"
2 Case Folding

2. Case Folding

Mengubah seluruh huruf dalam kalimat menjadi huruf kecil (lowercase) agar kata seperti "Kopi" dan "kopi" dianggap identik

Contoh: "Kopi Enak Cafe" → "kopi enak cafe"
3 Tokenizing

3. Tokenizing

Memecah teks kalimat menjadi urutan token kata individual berdasarkan pemisah spasi tunggal

Contoh: ["kopi", "enak", "banget", "cafe"]
4 Normalisasi

4. Normalisasi Slang

Mengubah bahasa gaul, singkatan chatting, dan kata tidak baku ke bentuk formal baku bahasa Indonesia (misal: "gk" → "tidak", "bgt" → "sangat", "yg" → "yang")

Contoh: "bgt" → "sangat", "gk" → "tidak"
5 Stopword

5. Stopword Removal

Menghapus kata-kata sambung umum yang tidak membawa bobot sentimen via kamus Sastrawi. Kata negasi ("tidak", "bukan", "belum") tetap dipertahankan agar konteks sentimen tidak hilang

Contoh: kata "yang" dibuang, kata "tidak" dipertahankan
6 Stemming

6. Stemming Sastrawi

Mengembalikan kata berimbuhan (awalan, sisipan, akhiran) menjadi bentuk kata dasar dengan algoritma Nazief & Adriani via Sastrawi O(1) set-lookup, lalu menyaring kata minimal 3 huruf

Contoh: "pelayanannya" → "layan", "menikmati" → "nikmat"
1 Group Split

1. Group Shuffle Split (80:20)

Pembagian data latih (80%) dan data uji (20%) berbasis ulasan unik (review_id) agar sub-kalimat dari satu review tidak bocor ke data uji (anti data leakage), serta menyaring duplikasi teks identik

Kaidah: review_id_train ∩ review_id_test = ∅
2 TF-IDF

2. TF-IDF Manual (L2 Norm)

Pembobotan kata manual: Sublinear TF 1 + ln(count), Smooth IDF ln((1+N)/(1+df)) + 1, dan normalisasi panjang dokumen Euclidean L2 v / √∑v² menggunakan representasi sparse CSR matrix

Formula: tfidf = (1 + ln(tf)) × (ln((1+N)/(1+df)) + 1)
3 Oversampling

3. Random Oversampling (ROS)

Diterapkan khusus pada data training untuk menyeimbangkan kelas minoritas ('negatif' dan 'netral') agar sama jumlahnya dengan mayoritas ('positif') dengan seed acak tetap (random_state=42)

Target: count(neg) = count(net) = count(pos)
4 Naive Bayes

4. Multinomial Naive Bayes Manual

Klasifikasi probabilistik dengan Log Prior ln(N_c / N) dan Log Likelihood Laplace smoothing α=1.0: ln((count(w,c) + α) / (∑count + α|V|)) tanpa library scikit-learn

Prediksi: argmax [ log P(c) + ∑ tfidf × log P(w|c) ]
5 Evaluasi

5. Evaluasi & Confusion Matrix

Pengujian model murni pada data testing tak terlihat untuk mengukur Akurasi, Precision, Recall, Macro-F1 (rata-rata unweighted per kelas), dan Weighted-F1

F1-Score: 2 × (P × R) / (P + R)
